# Additional documentation

This directory contains stable documentation for using and integrating the
Sonora source tree:

- NORA-HAL naming and API conventions;
- WM8904 clocking and supported sample rates;
- timer-HAL integration;
- AVAS configuration and line-model behaviour; and
- the full build and hardware-test procedure.

The root [README](../README.md) links to each document and describes the
recommended starting configuration.
